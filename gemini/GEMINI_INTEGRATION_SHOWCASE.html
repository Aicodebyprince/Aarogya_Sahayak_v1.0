  • ✓ Native Indic Multimodal Fluency: Direct comprehension in Marathi, Hindi, Bengali, Gujarati without translation lag.

  • ✓ Pydantic Validated Schemas: 100% structured JSON execution guaranteeing zero pipeline crashes.
  • ✓ DPDP-Compliant PII Masking: Automated regex & hashing scrambles all citizen identifiers before LLM ingestion.
